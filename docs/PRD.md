## 0. 프로젝트명

4구(사구) 당구 샷 경로 자동 안내 서비스

## 1. why - 목적

- 사용자가 4구 당구대 위 공 배치 사진 한 장만으로, 어디를 어떻게 쳐야 할지 알기 어려운 문제를 해결
- 실전에서 바로 따라칠 수 있는 수준(각도·힘 수치)의 캐롬 경로를 자동으로 계산해 제시함으로써 실력과 무관하게 최적의 샷을 선택할 수 있도록 지원

## 2. who - 타깃 사용자

- 4구 당구를 즐기지만 캐롬 경로(특히 뱅킹/고급 기술샷) 계산에 어려움을 겪는 사용자
- 매 타석마다 사진 한 장으로 빠르게 샷 가이드를 받고 싶은 모바일 웹 사용자

## 3. User Flow

1. **사전 설정:** 사용자가 자신의 큐볼 색상(흰공/노랑공)을 설정에서 미리 지정
2. **촬영/업로드:** 모바일 브라우저에서 당구대 사진 1장을 촬영 또는 업로드
3. **자동 인식:** 시스템이 테이블 경계와 공 4개(흰공1·노랑공1·빨간공2) 위치를 완전 자동으로 인식
   - 인식이 불확실한 경우, 사용자가 터치로 공 위치를 수동 보정 (fallback)
4. **경로 계산:** 시스템이 직접샷·뱅킹샷·고급 기술샷을 포함한 모든 가능한 캐롬 경로를 계산
5. **대표 샷 제시:** 기술 종류 우선순위(직접 < 뱅킹 < 고급기술) 기준 가장 쉬운 샷을 대표로, 각도·힘 수치와 함께 정적 2D 다이어그램으로 표시
6. **후보 탐색:** 사용자가 난이도 순 상위 3개 샷 후보를 탭/스와이프로 전환하며 확인

## 4. 기능 요구 사항

### P0 - 핵심 기능

- **사진 촬영/업로드(Capture):** 모바일 브라우저에서 단일 정지 사진 1장 업로드 (실시간 영상/AR 라이브 뷰 아님)
- **테이블·공 자동 인식(Vision Recognition):**
  - 사람 시점(비스듬한 각도) 사진 지원, 원근보정(캘리브레이션) 필수
  - 테이블 경계 및 공 4개(흰공/노랑공/빨간공×2) 위치를 완전 자동(AI)으로 인식
  - 인식 불확실/실패 시 사용자 터치 기반 수동 보정 fallback 제공
- **큐볼 설정 저장:** 사용자의 큐볼 색상(흰공/노랑공)을 설정에 미리 지정해 재사용 (매번 묻지 않음)
- **캐롬 경로 계산(Path Calculation):**
  - 직접샷, 1쿠션 이상 뱅킹샷, 고급 기술샷을 포함한 모든 가능한 경로 계산
  - 기술 종류 우선순위(직접 < 뱅킹 < 고급기술) 기준 최적(가장 쉬운) 샷을 대표로 선정
  - 실전에서 바로 따라칠 수 있는 수준의 각도(도)·힘(강도) 수치 산출
  - 유효한 캐롬 경로가 하나도 없는 경우, 가장 근접한(거의 성공할 법한) 샷을 참고용으로 제시
- **결과 시각화(Result Visualization):**
  - 원본 사진 오버레이가 아닌 재구성된 정적 2D 다이어그램으로 표시
  - 난이도 순 상위 3개까지 샷 후보를 탭/스와이프로 전환 가능

### P1 - 추가 기능

- **개인화 난이도 프로필(User Skill Profile):** 사용자 설문 기반 개인 난이도 기준 적용 (v1은 고정 기술종류 기준 사용, 차기 버전으로 보류)

## 5. Non-Goals (범위 제외)

- 실시간 카메라/AR 라이브 오버레이
- 점수 기록, 경기 이력 관리, 멀티플레이어 대전 모드
- 사용자 설문 기반 개인화 난이도 기준 (v2 이후)
- 100% 오차 없는 인식 보장 (수동 보정 fallback으로 대응, 완전 무결점 목표 아님)

## 6. Acceptance Criteria

- [ ] 사용자가 모바일 브라우저에서 당구대 사진 1장을 업로드하면, 시스템이 테이블 경계와 공 4개(흰공/노랑공/빨간공×2) 위치를 자동으로 인식한다
- [ ] 인식이 불확실한 경우 사용자가 터치로 공 위치를 수동 보정할 수 있다
- [ ] 시스템은 설정에 저장된 사용자의 큐볼 색상(흰공/노랑공)을 기준으로 경로를 계산한다
- [ ] 시스템은 직접샷, 1쿠션 이상 뱅킹샷, 고급 기술샷을 포함한 모든 가능한 캐롬 경로를 계산하고, 기술 종류 우선순위(직접 < 뱅킹 < 고급기술) 기준으로 가장 쉬운 샷을 대표로 제시한다
- [ ] 추천된 샷은 각도(도)와 힘(강도) 수치를 포함해 실전에서 바로 따라칠 수 있는 수준으로 제공된다
- [ ] 결과는 사진이 아닌 정적 2D 다이어그램으로 재구성되어 표시되며, 사용자는 여러 샷 후보를 탭/스와이프로 전환해 볼 수 있다
- [ ] 점수 기록, 경기 이력, 멀티플레이어 기능은 이번 버전에 포함되지 않는다
- [ ] 개인화 난이도 설문 기능은 이번 버전에 포함되지 않으며, 고정된 기술종류 기준이 사용된다
- [ ] 샷 후보가 여러 개일 경우 난이도 순으로 상위 3개까지만 표시한다
- [ ] 유효한 캐롬 경로가 하나도 없는 배치에서는 가장 근접한(거의 성공할 법한) 샷을 참고용으로 제시한다
- [ ] **MVP 완성 판정:** 서로 다른 실제 테이블 배치 10건을 테스트하여, 추천된 샷대로 직접 쳤을 때 7건(70%) 이상 실제로 맞으면 성공으로 간주한다

## 7. Ontology (핵심 엔티티)

| Entity                       | 구분        | 주요 필드                                                                             | 관계                                              |
| ---------------------------- | ----------- | ------------------------------------------------------------------------------------- | ------------------------------------------------- |

| Shot                         | Core domain | technique(직접/뱅킹/고급), angle, force, difficulty(기술위계 기준, v1 고정), sequence | computedFrom(BallPositions), rankedBy(difficulty) |
| UserProfile _(P1, deferred)_ | Supporting  | cueBallColor(프리셋), personalDifficultyPreference(v2 예정)                           | usedFor(v1: cueBall 식별 / v2: 개인화 난이도)     |

## 8. 참고 — 기술 스택 방향 (미확정, 그린필드)

- **프론트엔드:** 웹, 모바일 브라우저 카메라/파일 업로드 (`getUserMedia` 또는 `<input type="file" capture>`)
- **비전 인식:** 테이블 경계 검출(세그멘테이션/코너 검출) + 공 검출(색상/원형 검출 또는 객체 탐지 모델) + 원근 변환(호모그래피)로 실측 좌표 환산
- **경로 계산:** 2D 당구 물리 엔진(쿠션 반사각 계산 포함), 기술종류별 후보 열거 + 난이도(기술위계) 기준 랭킹
- **백엔드/설정 저장:** 큐볼 색상 프리셋 저장을 위한 경량 저장소(로컬 스토리지 또는 간단한 서버 설정)
